# SpendiT - Personal Budget Tracker

A simple and beautiful expense tracking web app built for managing daily spending in Ghanaian Cedis (GHS).

Live Demo: https://thunderous-nasturtium-01bf2b.netlify.app

### Features
- 💰 Track daily expenses (Food, Transport, etc.)
- 📊 Visual balance overview
- ➕ Add and manage expenses easily
- 🇬🇭 Built for GHS currency
- 📱 Responsive - works on mobile and laptop

### Tech Stack
- Flutter Web
- Deployed on Netlify

### How to Use
1. Open the live link
2. Add your expenses
3. Track your remaining balance
